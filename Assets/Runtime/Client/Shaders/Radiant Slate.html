Radiant Slate UI Style Guide

A refined evolution of Arcane Slate that preserves the same clean structure, restrained ornament, and premium dark-fantasy feel, while using lifted neutral values for much stronger readability in both bright and dark gameplay environments. The UI should stay neutral first, with fantasy identity carried by icons and selective accent usage rather than a tinted base palette.

Minimal Arcane structure Lifted neutral slate materials Thin steel borders Gold-led neutral accents Higher gameplay readability

Design Intent

Radiant Slate keeps the disciplined layout language of Arcane Slate, but removes the purple-biased base treatment. The palette is more neutral, slightly brighter, and more robust against real in-game lighting. The interface should feel calm, clean, and engineered, while the icon set carries most of the stylisation and fantasy expression.

Core Rules

  • Preserve the same flat planes, soft gradients, thin borders, and minimal bevel.
  • Keep the base UI neutral. Do not tint whole windows purple, teal, or any other fantasy hue.
  • Use gold as the primary UI emphasis colour for selected states, prestige, headings, and key affordances.
  • Reserve green, orange, and blue for semantic information such as health, warnings, and utility.

Typography

Keep the same modern, crisp type system. The palette shift does not change the type strategy.

Manrope Semibold / Bold
For headers, section titles, and modal titles
Inter Regular / Medium for labels, tooltips, settings, item text, quest copy, and system UI.
JetBrains Mono for timers, percentages, damage numbers, and exact values.

Panel Construction

  • Primary panel radius: 12–18 px equivalent.
  • Border thickness: visually 1–2 px.
  • Lift values slightly compared with Arcane Slate to improve panel separation.
  • Use subtle inner top highlight and restrained shadow; avoid glow-led framing.
  • Corners should stay rounded or softly cut, never ornate or carved.

Accent Usage

  • Gold is the main structural accent for selected states, tab underlines, headings, currency, and prestige.
  • Green supports health, positive feedback, and support-system clarity.
  • Orange handles warnings, damage, and urgency.
  • Blue supports mana, utility, and informational highlights.

Visual Notes

  • Titlebar is slightly brighter than the panel body for immediate structural clarity.
  • Selected tabs use gold underline rather than purple-tinted glow.
  • Slots are lighter than the base panel so icon silhouettes separate more clearly.
  • Fantasy identity should come primarily from icon art, portrait framing, and restrained accent colour.

Window-Specific Guidance

Inventory

Use slightly brighter slots than Arcane Slate, with clear borders and strong icon readability. Search, sort, and utility controls should stay integrated and neutral.

Quest Log

Active selection should use gold structural emphasis. Rewards can mix gold with restrained semantic colours where needed.

Character / Spellbook

A faint sigil or atmospheric backdrop is acceptable behind the model or spell grouping, but it must stay subordinate to text and stats.

What to Avoid

  • Purple-biased panels or colour-cast surfaces that make the whole UI feel tinted.
  • Overly dark backgrounds with low separation between window, slot, and text values.
  • Glow as a structural crutch for borders, tabs, or buttons.
  • Heavy bevels, carved frames, or ornamental trim that break the clean Arcane Slate layout language.
  • Too many simultaneous accent colours on one screen.
Radiant Slate should feel like the same family as Arcane Slate, but more production-safe: calmer base colours, clearer readability, and stronger resilience under varied gameplay lighting.
