## Offline export and verification

Until an archive location is supplied, run the following offline PowerShell procedure from the repository root with a new, empty destination. It copies the entire results tree, so failed, blocked and incomplete attempt directories are preserved too:

```powershell
$sourceResults = (Resolve-Path 'Builds/Benchmarks/Results').Path
$archiveRoot = 'D:/NinthAge-performance-archive-20261014'
if (Test-Path -LiteralPath $archiveRoot) { throw "Refusing to overwrite existing archive: $archiveRoot" }
New-Item -ItemType Directory -Path $archiveRoot | Out-Null
Copy-Item -LiteralPath $sourceResults -Destination (Join-Path $archiveRoot 'Results') -Recurse

$archiveResults = Join-Path $archiveRoot 'Results'
Get-ChildItem -LiteralPath $archiveResults -Recurse -Filter 'artifacts.json' | ForEach-Object {
    $manifest = Get-Content -LiteralPath $_.FullName -Raw | ConvertFrom-Json
    $runRoot = $_.Directory.FullName
    foreach ($file in @($manifest.files)) {
        $relative = [string]$file.path
        if ([string]::IsNullOrWhiteSpace($relative)) { throw "Empty artifact path in $($_.FullName)" }
        $present = ([string]$file.status -ne 'absent')
        if (-not $present) {
            if ([bool]$file.required) { throw "Required artifact is absent: $relative" }
            continue
        }
        $path = Join-Path $runRoot ($relative -replace '/', '\')
        if (-not (Test-Path -LiteralPath $path -PathType Leaf)) { throw "Missing artifact: $path" }
        $actual = (Get-FileHash -LiteralPath $path -Algorithm SHA256).Hash.ToLowerInvariant()
        if ($actual -ne ([string]$file.sha256).ToLowerInvariant()) { throw "SHA-256 mismatch: $path" }
        if ([long]$file.bytes -ne (Get-Item -LiteralPath $path).Length) { throw "Byte-count mismatch: $path" }
    }
}
```

The procedure includes `campaign.json`, `index.json`, each original `run.json`, `fixture.json`, `summary.json`, `report.md`, `artifacts.json`, bounded `samples.ndjson` and `logs/runner.log` where present. It refuses overwrite and performs no network upload.

After copying, verify every `sha256` and `bytes` entry in each `artifacts.json`, then verify the SHA-256 values of the copied `campaign.json`, `index.json` and each `artifacts.json` against this catalogue. A copied bundle that cannot reproduce these hashes is not an evidence archive. Do not upload it automatically; add a real retrieval reference here only after the user provides one.
